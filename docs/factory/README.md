# Factorycontext

Deze map maakt de PvdD-repository later geschikt voor Software Factory. De factory-aansluiting
wordt pas uitgevoerd na de technische fundering en functionele MVP. Tot die tijd zijn deze
documenten ook de compacte ontwikkelcontext voor directe wijzigingen.

Normatief blijft [de microservicespecificatie](../microservice-specificatie.md). Bij een conflict
gaat die specificatie voor. De uitvoeringsvolgorde staat in de drie stappenplannen.

- [Functionele specificatie](functional-spec.md)
- [Technische specificatie](technical-spec.md)
- [Ontwikkelen en verifiëren](development.md)
- [Deployment](deployment.md)
- [Lokale secrets](secrets-local.md)
- [Agent Runtime](agent-runtime.md)

Functioneel werk is geblokkeerd totdat T14 volledig groen is en de tag
`technical-baseline-v1` bestaat.
